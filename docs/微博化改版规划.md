# MiniForum 微博化改版规划（第三期）

> 本文档规划 **MiniForum（迷你微博论坛系统）** 的第三期迭代：深度复刻微博 PC 端体验。
> 技术栈：Spring Boot 2.7 + Java 17，内存存储（`ConcurrentHashMap`）+ JSON 文件持久化，无数据库，无前端框架，Session 认证。
> 设计原则：贴合现有轻量架构，简单可落地，每个功能形成完整的前后端闭环。

---

## 一、本期目标

在现有功能（关注流 / 通知 / 个人主页 / 阅读量 / 收藏 / 回收站等）基础上，做一次**微博式布局与信息架构升级**：

1. **帖子分类**：发帖可选择固定分类，左侧栏展示分类导航，支持按分类筛选信息流；
2. **热搜榜**：右侧栏展示热搜关键词榜 + 热帖榜，贴近微博「热搜」体验；
3. **三栏布局**：首页改为微博式三栏 —— 左栏分类导航 / 中栏（顶部发帖 + 信息流）/ 右栏热搜榜。

## 三、功能详情

### F13 帖子分类

**目标**：为帖子增加固定分类维度，支持按分类浏览，微博式左侧分类导航。

| 项 | 设计 |
|----|------|
| 分类集合 | 固定 12 类：全部动态（虚拟）、科技、数码、游戏、娱乐、体育、财经、汽车、时事、教育、生活、其他 |
| 数据模型 | `Post` 增加 `category` 字段（String，默认 `其他`）；旧数据兼容（`category` 为 null 时视为 `其他`） |
| 发帖 | 发帖框增加分类下拉（默认 `其他`）；`PostCreateDTO` 增加 `category`；`PostVO` 透出 `category` |
| 筛选 | `GET /api/posts?category=xxx` 按分类过滤（与 tag、分页可叠加） |
| 分类统计 | `GET /api/categories` 返回固定分类 + 各分类已发布帖子数（含"全部动态"总数） |

**接口设计**

```http
GET /api/categories
# 返回：[{name:"科技", count:12, icon:"💻"}, ...]  （固定分类顺序，count 为已发布帖子数）

GET /api/posts?category=科技&page=1&size=10
# 按分类筛选，返回分页结果（复用现有 PageResult）

POST /api/posts   # body 增加可选字段 category
```

### F14 热搜榜

**目标**：右侧栏展示热搜关键词榜，贴近微博热搜体验；点击热搜词跳转到对应标签筛选。

| 项 | 设计 |
|----|------|
| 热搜词来源 | 帖子标签（tags）作为热搜词（现有标签体系天然适合做话题词） |
| 热度计算 | 对每个标签：热度 = 关联已发布帖子的 `阅读量×1 + 点赞×2 + 评论×3` 求和（近 30 天窗口，时间越近权重越高） |
| 接口 | `GET /api/hot/search?limit=10` 返回 `[{keyword, heat, postCount, rank}]`，按热度降序 |
| 前端 | 右栏热搜榜：序号 + 关键词 + 热度值 + 帖子数；点击关键词跳转该标签信息流（复用现有 tag 筛选） |

**热度算法（近 30 天，时间衰减）**

```
对每个 tag T：
  heat(T) = Σ_{帖子 p ∈ 近30天且包含 T}
            ( p.viewCount×1 + p.likeCount×2 + p.commentCount×3 ) × weight(age)
  weight(age) = 1 / (1 + ageDays)        # 越新权重越高
  若 heat(T) = 0（无阅读/点赞/评论），则用帖子数兜底：heat = postCount×10
```

**接口设计**

```http
GET /api/hot/search?limit=10
# 返回：[{keyword:"AI", heat: 1520, postCount: 5, rank: 1}, ...]

GET /api/posts?tag=AI    # 前端点击热搜词时跳转（复用现有标签筛选）
```

> 说明：现有 `GET /api/posts/hot`（按阅读量的热帖榜）保留，作为右栏「热门帖子 TOP5」。

### F15 三栏布局改造

**目标**：首页 `index.html` 从单栏升级为微博式三栏。

| 改动点 | 说明 |
|--------|------|
| 布局骨架 | `.container` 改为 `.layout`（flex/grid 三栏），左栏 220px / 中栏 flex / 右栏 280px |
| 左栏 | 新增分类导航组件：从 `/api/categories` 拉取，点击切换 `activeCategory` 并刷新信息流 |
| 中栏 | 发帖框（加分类下拉）+ 数据看板统计条（保留）+ tabs + 帖子列表 + 分页 |
| 右栏 | 热搜榜（`/api/hot/search`）+ 热帖榜（`/api/posts/hot`）两个卡片 |
| 响应式 | `@media (max-width: 1024px)` 隐藏左右栏，仅留中栏（保持移动端可用） |
| 联动 | 左栏选分类 → 中栏 `latest` 流按分类过滤；点热搜词 → 切 tag 筛选；点热帖 → 跳详情 |

## 四、数据模型与持久化

- `Post` 实体新增字段：`private String category;`（默认 `其他`）；
- `PostCreateDTO` / `PostVO` 同步增加 `category`；
- JSON 持久化**天然兼容**：旧 `posts.json` 记录无 `category` 字段，Jackson 反序列化为 null，在 Service/VO 层兜底为 `其他`，无需数据迁移脚本；
- 新增热搜计算：无新实体，纯 Service 层聚合（基于现有 tags / viewCount / likeCount / commentCount）。
