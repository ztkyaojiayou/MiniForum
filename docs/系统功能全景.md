# MiniForum 系统功能全景盘点

> 本文档基于**源码实际核验**，盘点 MiniForum（迷你微博论坛系统）当前已实现的全部功能。
> 项目定位：一个类似微博的轻量博客系统，用于展示 **AI 辅助编程能力**。
> 更新日期：2026-08-14（第四期完成后的完整盘点）

---

## 一、项目概述

| 项目 | 内容 |
|------|------|
| 系统名称 | MiniForum（迷你微博论坛） |
| 技术栈 | Spring Boot 2.7.18 + Java 17 + Maven |
| 存储方案 | 内存存储（`ConcurrentHashMap`）+ JSON 文件持久化（`data/*.json`） |
| 认证方式 | Session 认证 + 登录拦截器 |
| 默认账号 | `admin / admin123` |
| 端口 | 8090 |
| 前端 | 原生 HTML/CSS/JS 静态页面，无前端框架 |
| 包名 | `com.tkzou.miniforum` |
| 中间件 | **零依赖**（无数据库、无 Redis、无 MQ、无 WebSocket） |

## 七、总结

MiniForum 已形成一条完整的微博核心闭环：

```
发帖（分类/标签/Markdown/话题）
  → 浏览（信息流/分类筛选/搜索/热搜/热门）
  → 互动（点赞/评论/收藏/转发/关注）
  → 通知（点赞/评论/关注/转发 → 通知中心）
  → 私信（会话/聊天）
  → 个人中心（我的帖子/草稿/收藏/回收站/资料）
```

技术特点：**零第三方中间件**，纯内存 + JSON 持久化，全部功能形成前后端完整闭环，适合作为 AI 辅助编程能力的完整演示项目。
