# 微博推荐产品与分发机制调研

> 日期：2026-08-24 ｜ 用途：MiniForum 推荐系统场景适配依据（配套 [推荐系统设计方案](./推荐系统设计方案.md)）
> 方法：WebSearch 多轮检索 + 公开官方规则/专利/技术分享 + 行业认知综合。产品形态有公开来源支撑；**权重/公式为方向性经验值，需按自身数据 A/B 调参**。

---

## 一、信息流产品：双流/三流制

- 微博首页现为 **"关注 / 推荐 / 热点" 三流并进**（ITBear 2025-10）。
- **关注流**：时间线为主，提供"智能排序/时间排序"切换；智能排序会插"你关注的人关注了 X""好友赞过"等社交卡。
- **推荐流**：纯算法个性化，依据兴趣标签、关注关系、实时热点、热门内容召回排序；提供"关闭个性化推荐"开关。
- **形态**：单列信息流（一条一屏），非小红书双列瀑布流。
- **产品历程**：早期纯关注时间线 → 2012 智能排序 → 2017-18 大规模推荐流（被批"从我想看到要你看"）→ 多轮做减法。

**启示**：实现两套排序引擎——关注流=时间倒序（默认，可智能排序）；推荐流=兴趣+热度+社交+时效。关注流可穿插少量社交卡/推荐卡。

## 二、热搜榜（本项目已有 HotSearchService）

- **热搜 vs 热门微博 vs 话题**：
  | 产品 | 聚合单位 | 排序逻辑 |
  |---|---|---|
  | 热搜榜 | 关键词/搜索词 | 搜索量+讨论量+传播量，实时 |
  | 热门微博 | 单条博文 | 互动热度+时效 |
  | 话题 #xx# | 主题聚合页 | 讨论量/阅读量 |
  | 超话 | 垂直粉丝社区 | 签到/积分/等级 |
- **官方规则**（2021 首次公开）：热度由**搜索行为、讨论量（发帖/发博）、互动**综合计算；对权威媒体/官方信源加权；剔除营销/低俗/刷量/谣言；排序中不存在商业售卖位置；有降权/控量/去水机制。
- **2026 升级**：新增排序维度，打击"灌水刷评/蹭热词/货不对板"，日均净化约 40 个词条；垂直领域热点占比升至 38%，文娱占比降 23%。
- **热度建模**（专利佐证指数衰减）：`hotScore = (w_search·log1p(搜索量) + w_discuss·log1p(讨论量) + w_interact·log1p(互动)) × decay(age) × burst_bonus × authority × anti_spam`，权重 `w_search > w_discuss > w_interact`。

**启示**：热搜=搜索次数+话题/博文讨论量聚合，滑动窗口统计；做"词条-内容匹配度"过滤蹭热点；热搜可给推荐流兜底。

## 三、互动信号权重（核心）

- **微博信号优先级：转发 > 评论 > 点赞 > 收藏 > 浏览**。
- 专利 CN108733763A 明确"**阅读数所占权重值最低**"；专利 CN109783712B 将转发/评论视为核心影响力信号。
- 转发=二次传播/裂变（传播树），是微博传播引擎；评论=深度卷入；点赞=浅互动；阅读=被动曝光（主要当曝光分母）。
- **互动率 vs 绝对量并重**：只按绝对量排序会造成大V马太效应，应同时看互动率（互动/曝光）这一相对质量指标。

**启示（本项目落地权重）**：`转发 3 / 评论 2 / 点赞 1 / 收藏 1.5 / 浏览 0.02`；互动率单独作为 f_quality 特征。

## 四、时效性（强衰减）

- 微博内容有效生命周期**几小时~一两天**，热点分钟级。
- 时间衰减用**指数衰减**（专利 CN109190033A：`T(t_k)=Σ e^{-θ·t_k}`），半衰期约 2~6 小时；新内容（发布<1h）给基础曝光兜底。

**启示**：`f_recency = exp(-ln2·age_hours/half_life)`，half_life≈4h（推荐流）/6h（关注流）；新帖小流量试探。

## 五、关注关系与二度关系

- 微博是"半熟社交+媒体"：关注流保底（明确订阅），推荐流扩圈。
- **二度关系**（"你关注的人转发了什么"）很重要：等于让大V替用户做了一轮"人"的筛选。

**启示**：`f_social = 1 + 1.0·(作者=我关注) + 0.5·(我关注的人转发过)`，亲密度可用近 30 天互动频率度量。

## 六、兴趣标签与话题召回

- 微博兴趣单元天然是**话题(#...#)与超话**；注册引导用户选兴趣话题。
- 专利 CN108197330B：获取"用户兴趣标签字典" + 结合关注关系确定候选推荐集合。
- ItemCF 在微博场景的 Item 粒度=微博正文，相似度可由"共同互动 + 共同话题/标签"构成；也可把话题做两级召回。

**启示**：画像按话题聚合（带时间衰减）；ItemCF 叠加共同话题/标签相似度；TopicRecall 独立一路。

## 七、冷启动

- **新用户**：兴趣选择 → 话题池；热搜/热点兜底；该领域热门作者/大V内容填充；尽快进入 E&E（Thompson bandit）。
- **新微博**：小流量试探机制——发布~15min 给作者粉丝+冷启动池基础曝光 E0；15min~2h 按互动率 r=interactions/exposure 打分，达标扩量、不达标收量；>2h 进常规排序。初始曝光下限=作者粉丝数 log1p。

## 八、探索与利用

- 热点与个性双驱动：热搜/热门榜单管"热点"，信息流管"个性+热点混合"。
- 弱训练侧用 **Thompson sampling**：对候选维护 Beta(α,β)，α=正向反馈，β=负向反馈；`最终分 = 利用分×(1-λ) + 采样分×λ`；λ 随行为量衰减（新用户 0.5~0.8，老用户 0.1）。可按话题作为臂。

## 九、弱训练侧 rankScore 建议

```
rankScore = ( 0.30·f_interact + 0.20·f_quality + 0.30·f_interest
            + 0.15·f_social  + 0.10·f_author + 0.10·f_hot
            + λ·explore_bonus ) × f_recency(age, half_life≈4h)
```

- 特征均 `log1p` 归一化；核心逻辑：**深度互动>浅互动、互动率与绝对量并重、时效强衰减、兴趣+社交+热点合成、作者权重保底**。
- 关注流配方：social 0.55 / interest 0.10 / half_life≈6h；热搜走独立"搜索驱动+去水"公式。

## 十、评估指标

- 信息流：**互动率（深度互动/曝光）、转发率、评论率/点赞率、停留/时长、新增关注转化**（半熟社交核心商业指标）。
- 热搜：词条点击率、停留、刷新频次、词条持续时间、讨论增量；生态健康度=榜单多样性、去水效果。
- 离线评估：用历史曝光日志构造正负样本（曝光有深度互动=正，无=负），算 AUC/排序互相关；关注多样性/覆盖度/时效性（内容平均年龄）。

## 十一、微博 vs 小红书差异速查

| 维度 | 微博 | 小红书 |
|---|---|---|
| 信息流 | 单列、重时效刷 | 双列瀑布流、慢浏览 |
| 时效性 | 极强（分钟~小时） | 中等（月~年级长尾） |
| 关注权重 | 强（关注流根基） | 弱（去中心化） |
| 信号权重 | **转发最高** | 收藏权重高 |
| 分发 | 粉丝基础传播+算法放大 | 内容标签+流量池赛马 |
| 冷启动 | 热搜/热门兜底+默认关注 | 流量池赛马 |

**结论**：仿微博应强化"热点+关注+转发传播"，不要把小红书式"收藏优先/长尾/双列"当默认。
