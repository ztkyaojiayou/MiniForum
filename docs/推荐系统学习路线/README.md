## 一、这是什么？

这是一套**面向零基础 / 跨行学习者的推荐系统学习路线**，共 6 步 + 1 份总览，全部整理成 Markdown 文档放在本目录。

它不教你背公式、不逼你啃论文，而是按**真实工业界做推荐系统的方式**带你走一遍：

```
数据从哪来 → 怎么变成样本 → 怎么变成特征 → 怎么在线服务 → 怎么验证效果 → 怎么创造业务价值
```

**核心信念（请先记住这句）**：

> **推荐系统本质是一个大型系统，不是模型，不是纯算法。**
> 模型只占 20%，剩下 80% 是数据、工程、实验、监控。

所以这份路线里，模型知识只讲"够用"，**数据和工程讲透**——因为这才是真实工作的日常。

## 四、怎么用这份路线？（最重要的一节）

### 4.1 阅读顺序（别跳！）

```
① README.md        → 花 5 分钟，搞清整体
② 00-总览与索引.md   → 花 20 分钟，建立全景，做前置知识自检
③ 01 → 02 → 03 → 04 → 05 → 06   → 按顺序，每步都要动手
```

**为什么不能跳步？** 因为每一步的产出是下一步的输入：

```
没有第1步(数据)     → 第2步(样本) 无米下锅
没有第2步(样本)     → 第3步(特征) 无从谈起
没有第3步(特征)     → 第4步(在线) 模型没有输入
没有第4步(在线)     → 第5步(实验) 没有东西可测
没有第5步(实验)     → 第6步(业务) 无法证明价值
```

跳一步，后面全是空中楼阁。

### 4.2 每份文档怎么读（统一结构）

每份文档都是同一个 7 段式结构，帮你快速定位：

| 段落 | 作用 | 新手建议 |
|------|------|---------|
| 1. 一句话核心认知 | 每步最本质的一句话 | **必须背下来** |
| 2. 核心概念与原理 | 讲清楚"是什么、为什么" | 第一遍必读 |
| 3. 关键技术细节 | 表结构/伪代码/方案示例 | 第一遍浏览，动手时精读 |
| 4. 工程落地要点 | 真实系统怎么做的 | 动手做 demo 时对照 |
| 5. IoT 认知补全 | 工程背景怎么平移 | 纯新手可跳过 |
| 6. 常见坑与避坑 | 前人踩过的坑 | **动手前先看，省一个月** |
| 7. 自测题 | 5 道题检验是否真懂 | 每章看完必做 |

### 4.3 时间安排

| 步骤 | 建议时长 | 节奏建议 |
|------|---------|---------|
| 第1步 埋点+数据管道 | 2 周 | 每天 2~3 小时，重点在动手搭事件模型 |
| 第2步 样本生产 | 1 周 | 概念难，动手简单，别卡太久 |
| 第3步 特征平台 | 1~2 周 | 工程性强，你的强项区 |
| 第4步 在线链路 | 1~2 周 | 最重的一步，模型原理够用即可 |
| 第5步 AB实验+监控 | 1 周 | 统计概念要补，但别钻太深 |
| 第6步 业务闭环 | 持续 | 伴随整个学习过程理解 |

**总计约 6~9 周**，建议每周至少 20 小时。

### 4.4 最重要的学习原则

```
1. 每步都要动手，不做 demo 等于没学
2. 先追求"系统能转"，再追求"模型更准"
3. 一个能跑通全链路的小系统 > 十个孤立的 SOTA 模型
4. 卡住了先往后看，回头再补，不要原地死磕
```

## 五、新手常见疑问（FAQ）

**Q1：我是纯小白，没有编程/工程基础，能学吗？**
能，但要更慢。建议先补一点 Python 基础和 SQL，再看本路线。路线里大量内容是工程和数据，纯概念部分并不难。

**Q2：要学多少数学？**
够用就行。推荐系统 90% 的工作不需要高深数学。理解"向量、内积、相似度、概率、分布"这几个概念就够起步。深度学习部分到第 4 步再补 Embedding 和注意力即可，不用先啃微积分。

**Q3：要先看完《推荐系统实践》再开始吗？**
不用。**先看 README 和 00 总览，直接进第 1 步，边做边看书**。书是字典，不是教材顺序。想做知识体系的可以配合 00 里的书单看。

**Q4：需要自己搭集群吗？**
不需要。学习阶段用公开数据集 + 单机即可：
- 数据管道可以用简化版（脚本 + 本地消息队列模拟）
- 向量检索用 Faiss（单机库）就够，不用上 Milvus 集群
- 在线链路可以用 Flask/FastAPI 起一个最小服务

**Q5：学完能面试吗？**
能。本路线覆盖了工业界推荐系统的完整链路，面试常问的"召回/排序/特征/样本/AB 实验"全部覆盖。建议学完后按第 5 步把"做过的一个推荐系统"完整讲出来，比背八股强十倍。

**Q6：文档里反复提到 IoT，我不是 IoT 背景有影响吗？**
没有。那些是"扩展阅读"性质的对照内容，帮助有工程背景的人加速理解。跳过完全不影响主线。

**Q7：学不动了怎么办？**
正常，第 2 步（样本）和第 4 步（在线链路）最容易劝退。记住：**这些内容 80% 的人学一遍都不懂，你是来补认知的，不是来背公式的。** 看懂"为什么这么设计"就及格，细节等真正做项目时再补。
